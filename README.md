# 🛍️ Garment Shop - Bento Grid UI

## ✨ Features

*   **🧩 Bento Grid Design:** A modern, asymmetrical layout with beautifully rounded corners and a premium feel.
*   **📱 Fully Responsive:** Seamlessly adapts to mobile phones, tablets, and large desktop screens.
*   **✨ Interactive Animations:** Smooth hover effects, slide-up text, and polished micro-interactions.
*   **👗 Category Sections:** Dedicated grid spaces for Menswear, Womenswear, Accessories, and Featured Outfits.
*   **🚀 Lightweight:** Built with pure HTML and CSS for lightning-fast loading speeds.

## 🛠️ Tech Stack

*   **HTML5:** Semantic markup for structure and accessibility.
*   **CSS3:** Custom properties (variables), CSS Grid, Flexbox, and responsive media queries.
*   **JavaScript:** (Optional) Minimal vanilla JS for mobile menu toggling or dynamic interactions.

## 🚀 Getting Started

To view or modify this project locally, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/kashyupDhruv/bentu-ui-website](https://github.com/kashyupDhruv/bentu-ui-website)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd garment-shop-bento
    ```
3.  **Open the project:**
    Simply double-click the `index.html` file to open it in your default web browser, or use a tool like VS Code Live Server for hot reloading.
